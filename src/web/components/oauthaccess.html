OAuth Access
Protect endpoints with OAuth 2.0 authentication (similar to Cloudflare Access)

How OAuth Access Works

OAuth Access protects your proxy endpoints with OAuth 2.0 authentication. When enabled on an endpoint:

  1. Users visiting the endpoint are redirected to your OAuth provider (Google, GitHub, Azure AD, etc.)
  2. After successful authentication, users are redirected back to Zoraxy
  3. Zoraxy validates the user and creates a session
  4. Users can access the protected endpoint for the session duration
